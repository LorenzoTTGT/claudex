# ClickUp Done

This skill is user-triggered only. Do not invoke it automatically after implementation.

When invoked, gather the recent diff/commits, prepare a clear completion comment, optionally attach available verification screenshots, mark the task done, update any local tracker, and report the exact comment and status update result.
