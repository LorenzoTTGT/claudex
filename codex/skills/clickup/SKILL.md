# ClickUp Task Fetch

Fetch the requested task and attachments, then summarize task ID, URL, title, status, priority, list/project, assignees, due date, description, tags, checklists, and attachments.

If image attachments are downloaded locally, display them with the image/read tool when available.

Do not change task status, post comments, or mark work done from this skill.
